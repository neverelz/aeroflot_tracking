## 🤖 Настройка Telegram-бота

### Шаг 1: Создать бота
1. Откройте Telegram и найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя (например: `Aeroflot Price Tracker`)
4. Придумайте username (например: `my_aeroflot_tracker_bot`)
5. Скопируйте **токен** вида: `1234567890:ABCDefGhIJKlmNoPQRsTUVwxyZ`

### Шаг 2: Получить Chat ID
1. Найдите в Telegram **@userinfobot**
2. Отправьте ему любое сообщение
3. Он ответит вашим Chat ID (число, например `123456789`)

### Шаг 3: Активировать бота
- Обязательно отправьте боту **любое сообщение** (`/start`), иначе он не сможет вам писать!

## 📬 Уведомления в Telegram

Бот присылает сообщение:
- ✅ Всегда при **тестовом запуске** (`--test`)
- 🔥 Когда цена **ниже порога** (по умолчанию 15 000 ₽)

## 🛡️ Защита от блокировки

Сайт Аэрофлота защищён от ботов. Скрипт использует:
- **Видимый браузер** (non-headless) — выглядит как обычный пользователь
- **Реалистичный User-Agent** Chrome
- **Случайные задержки** между действиями
- **Скриншоты** при ошибках для отладки

Если появится **капча** — скрипт сохранит скриншот (`screenshot_*.png`) и отправит уведомление в Telegram.
